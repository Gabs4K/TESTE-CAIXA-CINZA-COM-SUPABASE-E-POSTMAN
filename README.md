**3.1 Como o projeto foi criado:**
Foi criado um novo projeto na plataforma Supabase para a realização da atividade de testes caixa cinza em uma API de autenticação. O projeto foi utilizado para disponibilizar o ambiente de autenticação, gerenciar o usuário de teste e obter as informações necessárias para realizar as requisições HTTP pelo Postman.
---
**3.2 Qual tipo de autenticação foi utilizada:**
Foi utilizada a autenticação por e-mail e senha, disponibilizada pelo Supabase Auth. Nesse método, o usuário informa seu endereço de e-mail e sua senha para realizar o login. Para facilitar a execução dos testes, a opção de confirmação de e-mail foi desabilitada no ambiente, permitindo utilizar o usuário de teste sem passar por essa etapa de confirmação. A API verifica as credenciais enviadas e retorna uma resposta indicando se a autenticação foi realizada com sucesso ou se ocorreu algum erro.
